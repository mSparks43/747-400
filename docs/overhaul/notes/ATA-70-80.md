### 2.2 部品と電源（CF6 は ATA、PW は FCOM と LH）

- EEC: 2 channel の FADEC。両 channel とも計算し、駆動は channel in control だけ。N2 76% 以上に達した始動ごとに交代 (ATA70_80 p.172・p.177 (73-21))。
- EEC の電源: AGB の専用 alternator (FCOM p.875 (7.20.5))。CF6 は N2 9% 超で alternator が全電力を供給。機体の 28 V DC は FUEL CONTROL RUN、start relay、EEC ground test のときだけ (ATA70_80 p.177・p.180・p.200–201)。推定: 始動前と停止後（N2 <9% かつ CUTOFF）は EEC が無電源。
- 燃料弁: spar valve（主タンク内、28 V DC hot battery bus のモーター）、engine fuel valve（HMU の PRSOV を latching の HPSOV solenoid で開閉、28 V DC main battery bus）(ATA70_80 p.166–169・p.235 (73-21))。
- 点火: 1 基に exciter と igniter が 2 系統。系統 1 = 115 V AC BUS 1、系統 2 = AC BUS 3、予備 = 115 V AC STBY bus。exciter への通電は ECU (ATA70_80 p.252–265 (74))。
- 始動: AGB の air turbine starter、start valve（ばねで閉、ECU が健全な 1 channel の coil を駆動）、START switch の hold-in solenoid（28 V DC APU battery bus、N2 speed card の <50% 接点で地絡）(ATA70_80 p.536–559 (80-11))。
- 逆推力（CF6）: translating cowl 2 枚に空圧の CDU。T/R PRSOV、DPV、CDU の位置スイッチと RVDT、レバーの interlock actuator。Eng n は DC bus n (ATA70_80 p.400–462・p.472–475 (78))。
- オイル（CF6）: タンク約 8 US gal、低圧スイッチ、filter ΔP スイッチ、温度・量センサー (ATA70_80 p.488・p.518–525 (79))。
- 振動（CF6）: 加速度計 2 個（No.1 bearing、CRF）、signal conditioner 2 台 (ATA70_80 p.358–367 (77-31))。
- 表示: N1・N2・EGT・FF は ECU から ARINC 429 で EIU（3 台）へ。N1・N2 には EIU への analog backup がある (ATA70_80 p.321・p.326–327・p.336 (77))。

## 3. 操作と表示

### 3.1 操縦席の操作

- Thrust levers: reverse lever は forward lever が closed のときだけ上がり、forward lever は reverse lever が down のときだけ前に出る。reverse lever は auto speedbrake を作動させる (FCOM p.859 (7.13.1))。
- FUEL CONTROL（RUN / CUTOFF）(FCOM p.860 (7.13.2)):
  - RUN（autostart ON、109/570）: spar valve と engine fuel valve を開。EEC が start valve、fuel metering valve、igniter を順に制御。
  - RUN（autostart OFF と 405）: spar valve と engine fuel valve を開、igniter に通電。
  - CUTOFF: 燃料弁を閉、igniter 電源を断、Demand pump selector が AUTO なら当該 demand pump を作動、Engine Fire switch のロックを外す。
- START switch: 引くと（autostart ON）start valve を arm し engine bleed air valve を開。（autostart OFF と 405）start valve と bleed air valve を開。N2 50% で戻り、start valve と bleed air valve が閉じる。Start light（白）は start valve 開 (FCOM p.862・p.864 (7.13.4–6))。
- STBY IGNITION（1 / NORM / 2）: NORM は AC が選択 igniter に給電し、AC が無いと standby が連続給電（GE は全 igniter、PW は igniter 1）。1・2 は standby が当該 igniter に連続給電 (FCOM p.862–863)。
- CON IGNITION: ON で選択 igniter が連続作動。405 と 570 は approach idle の最小値も指令 (FCOM p.863)。
- AUTO IGNITION: GE は SINGLE（地上始動 2 回ごとに igniter 1/2 を交代、空中始動と flameout は両方）/ BOTH。109 は 1・2（autostart ON なら交代と空中両方、OFF ならその igniter）/ BOTH。405 は選んだ igniter (FCOM p.863–864)。
- 選択した igniter が作動する条件: 始動中で N2 <50%、TE flaps が UP 以外、NAI ON、flameout（GE）、autostart ON で flameout（109）(FCOM p.863–864)。
- ELEC ENG CONTROL（NORM / ALTN）と ALTN light（amber、alternate 選択時）。EEC MAINT POWER（NORM / TEST、停止中の試験用電源）(FCOM p.864–865 (7.13.6–7))。
- Display Select panel の ENG で二次エンジン表示、CANC / RCL で超過の red box を取消・再表示 (FCOM p.872–873 (7.20.2–3)、p.1047 (10.10.85))。

### 3.3 二次エンジン表示と表示形式

- 内容: N2、FF、OIL P、OIL T、OIL Q、VIB。digital の枠は N1・EGT・N2・FF。FF と OIL Q は digital のみ (FCOM p.842 (7.11.2)、p.872 (7.20.2))。
- 自動表示: EICAS に最初に電源が入ったとき、空中で FUEL CONTROL を CUTOFF にしたとき。ENG スイッチで消せる (FCOM p.843 (7.11.3)、p.872)。
- Partial format（ENG を選んでいないとき）: GE は N2 が限界、OIL P 低下と OIL T 上昇が caution 域か限界、OIL Q low、OIL Q differential 超過、VIB が display indicator に達すると、その項目だけ出す。PW は OIL P が限界のときだけで、differential は無い。ENG で全表示、もう一度で partial に戻る。別の二次表示を選ぶと partial は主 EICAS に compact で出る。超過が正常域に戻るまで partial と cue は残る (FCOM p.852–854 (7.11.12–14)、p.874–875 (7.20.4–5))。
- Compact format（EICAS に使える画面が 1 枚）: 主パラメータ（GE は N1、PW は EPR）だけ bar、他は digital。ENG で二次を追加。1 画面で二次の超過が起きたら主 + partial を compact で出す (FCOM p.855–857 (7.12)、p.874)。
- 始動の表示 (FCOM p.843–851・p.857・p.879):
  - EGT start limit（赤線）: FUEL CONTROL CUTOFF で表示し、N2 が所定値に達するまで。達すると EGT が赤。
  - Fuel-on indicator（N2 上）: CUTOFF で表示。手動始動で RUN にする最小 N2。GE と 109 は magenta。CF6 の ATA は 15% N2、cyan、fire switch が引かれていないこと (ATA70_80 p.346 (77-12))。
  - X-BLD（magenta）: in-flight start envelope 表示中で、速度が windmill 始動に足りないとき (FCOM p.851 (7.11.11))。

## 4. 内部ロジック

### 4.1 EEC normal mode（推力設定）

- 共通（FCOM）:
  - EEC は full authority で、レバー入力で前進と逆推力を制御する (FCOM p.875 (7.20.5))。
  - GE は idle と max N1 の間で N1 を計算し、実 N1 が一致するよう燃料を調整する。PW は EPR で同じ (FCOM p.875–876)。
  - 安定後は外気温・気圧が変わっても推力を一定に保ち、NAI・WAI・与圧の抽気の変化も補正する。そのため上昇中にレバーを固定できる (FCOM p.876 (7.20.6))。
  - Max N1/EPR はその条件の最大定格推力。EEC が常時計算し、full forward で max に制限する。どのフェーズでも full forward で最大推力が出る (FCOM p.876)。
- CF6（ATA）:
  - TLA critical points（lever 角 / resolver 角）: idle 0° / 34.88°、flat idle upper 2°、takeoff thrust 48°、forward stop 50°。reverse 側は flat idle lower 48.5°、max reverse 84.5°、stop 89.25°。T/R switches は reverse 6–30° で閉 (ATA70_80 p.146–151 (73))。
  - N1 指令は FWD IDLE から CLIMB 位置まで直線、その先は rating ごとの plateau（図）。full forward の rating: TO は PA <17,000 ft かつ <300 kt、MCT は 18,000–22,000 ft または >293 kt、CLB はレバー >35° かつ >25,000 ft。TO→MCT と MCT→CLB は遷移帯 (ATA70_80 p.208–209 (73-21))。推定: 遷移帯は 17–18 kft・293–300 kt と 22–25 kft の補間。
  - rating は ADC の T・P・Mach から標準大気に補正し、FMC の bleed configuration を加える。rating plug（J14）が rating table を選ぶ (ATA70_80 p.159・p.172・p.178・p.204)。
  - FMC からの N1 trim は A/T ARM のときだけ。最大差 3%（19,500 ft 未満）/ 5%（超）(ATA70_80 p.217–218 (76-12))。A/T 側の機能。
  - 加減速: N1・N2 の最大変化率で燃料を制限し、減速では flameout しない下限を保つ。全エンジンが同じ TLA 変化に同じ速さで応答する (ATA70_80 p.205)。数値は資料に記載なし。
  - 最低燃料流量 594 pph。ECU の信号を失うと FMV は min flow 側に寄る (ATA70_80 p.165)。
- PW: EPR を制御量にすること以外（rating、TLA の角度、加減速）は資料に記載なし。

### 4.2 Alternate mode と reversion

- FCOM（共通）(FCOM p.876–877 (7.20.6–7)):
  - alternate は normal の backup。EEC が normal を続けられないと自動で移り、ELEC ENG CONTROL で手動でも選べる。
  - Max N1/EPR での制限が無く、max には full forward より手前で達する。環境や抽気が変わるたびにレバーを調整する。
  - 同じレバー位置で normal 以上の推力。自動移行では推力は変わらない。手動選択では推力が増えるので、idle より上ならレバーを先に戻す。
  - ALTN で full forward にすると overboost。地面への衝突が迫った緊急時だけ。
  - どれかの EEC が ALTN に移ると A/T が切れる。GE は全 EEC を手動で ALTN にすれば A/T を再び使える。PW は全 EEC が normal に戻れば使える。
  - PW は逆推力中、EPR の精度のため表示なしで ALTN を選ぶ。
- PW の ALTN 運用: FMC に組み込まれておらず A/T は使用禁止、離陸推力は手動、4 基とも ALTN (FCOM p.322 (PI.18.10))。
- CF6（ATA）:
  - Soft reversionary（自動）: ADC 喪失で入る。RAM の最後の有効値を使い、P0 は ECU 内、Mach は計算。ambient が大きく変わると overboost の可能性 (ATA70_80 p.204・p.207 (73-21))。
  - Hard reversionary（手動 ALTN）: 不揮発の cornerpoint 温度を使い、P0 の変化だけ補正。同じ P0 で最大の N1 を出す。全エンジンを揃えるためのモード (ATA70_80 p.205・p.207)。
  - ALTN light は手動選択か、ECU の REVERSIONARY MODE 接点（N2 >50% のとき）で点く (ATA70_80 p.202–203・p.245)。
  - 入力喪失: TAT は T12、P0 は ECU 内で代替。PT を失うと reversionary。TLA を両方失うと takeoff 域では最後の値を保持、それ以外は idle (ATA70_80 p.204・p.225)。
  - 両 channel が制御不能なら ENG n CONTROL、FMV は min idle stop（p.231）。p.227 の図は「engine shutdown」で食い違う。
- メッセージ: ENG n EEC MODE、>ENG n LIM PROT（§3.5）。

### 4.3 オーバースピード保護

- idle より上では EEC が N1 と N2 を監視し、限界に近づくとレバーの要求があっても燃料を減らす (FCOM p.878 (7.20.8))。
- CF6: N1 3,854 rpm（117.5%）、N2 11,055 rpm（112.5%）、PS3 430 psid を超えないよう TLA に関係なく燃料を削る。HMU の機械式 governor は N2 113%（最大 113.4%）(ATA70_80 p.165・p.205)。
- >ENG n RPM LIM は「EEC が red line で推力を制限している」表示（GE は N2、PW は N1 か N2）(FCOM p.901)。ATA の名前は ENG n RPM LIMIT で「N1 overspeed」(ATA70_80 p.231)。FCOM に従う。

### 4.4 アイドル選択

- min idle と approach idle。approach idle は空中で NAI ON、flaps landing、CON ON（405・570）のとき。go-around の加速時間を短くするためで、接地 5 s 後に min idle へ。GE は逆推力作動中も approach idle (FCOM p.863、p.877–878 (7.20.7–8))。
- CF6:
  - min idle は N2 6,050 rpm（61.6%）。approach (flight) idle は ambient T・P から計算し 73% N2 以下。PS3 が抽気要求に足りなければ燃料を増やす (ATA70_80 p.206・p.208)。
  - ECU は MIN IDLE の ground discrete があるときだけ min idle。discrete は idle select relay R7322（通常 energized）から T/R relay R7142・R7128 を通る (ATA70_80 p.210–211)。
  - R7322 が切れる条件は空中で NAI ON、空中で TE flaps landing（図は >23°。Eng 1/4 は L FCU、2/3 は R FCU）。逆推力要求で T/R relay が energized になっても切れる (ATA70_80 p.210–211)。
  - 接地後 5 s 遅れて min idle (ATA70_80 p.210)。推定: 空中で条件が外れたときも 5 s 遅れる（p.211 の回路から）。
  - ATA は CON を条件に挙げない。FCOM に従う。
- ENG n LOW IDLE、>IDLE DISAGREE（CF6: 全機 min のはずが 1 基以上 approach）(FCOM p.900・p.902、ATA70_80 p.230)。
- PW: 値と relay は資料に記載なし。

### 4.5 燃料制御スイッチ・燃料弁・停止

- spar valve、fuel metering valve、engine fuel valve の 3 弁が開くと燃料が流れる。開く条件は Fire switch in、FUEL CONTROL RUN、エンジンの燃料ポンプ圧（N2 回転中）。autostart 中は metering valve を EEC が別に制御する。CUTOFF か Fire switch out で 3 弁とも閉 (FCOM p.886 (7.20.16))。
- CF6:
  - RUN で HPSOV の RUN coil と spar valve OPEN、CUTOFF で CUTOFF coil と spar CLOSE。Fire switch を引くと FUEL CONTROL に関係なく HPSOV cutoff と spar CLOSE (ATA70_80 p.168–169・p.234–235)。
  - RUN でも PRSOV が開くのは metering valve が min flow stop より上のとき。autostart では RUN でも ECU が FMV を 0 に保ち、必要時に start setting まで開く (ATA70_80 p.165–168)。
  - CUTOFF で ECU の fault flag をリセットし不揮発に記録 (ATA70_80 p.200–201)。
  - PRSOV の実位置と指令の不一致が 5 s で ENG n FUEL VLV。spar valve の不一致は FUEL SPAR VLV n（status）(ATA70_80 p.168–169)。
- FF は engine fuel valve の下流で計測し、二次表示と FMS へ送る (FCOM p.886)。CF6 は HMU と IDG HX の間の質量流量計で、ECU 経由 (ATA70_80 p.128–130)。
- ENG n FUEL FILT は CF6 で ΔP 23 psid、bypass は約 35 psid (ATA70_80 p.118・p.134–135)。

### 4.6 始動

- 空気: 通常は APU。地上空気と運転中エンジンのクロスブリードも可 (FCOM p.879 (7.20.9))。
  - 地上空気はダクト圧が最低 30 psi（気圧高度 1,000 ft ごとに 1 psi 減）。クロスブリードは運転中エンジンを約 70% N2 にする (FCOM p.183 (SP.7.1))。
  - 通常始動では pack を 2〜3 台 OFF (FCOM p.123 (NP.21.29))。
  - START で PRSOV が逆流を許して starter に空気が行く。start valve が開くと ASCTU が PRV を閉じ、start valve が閉じた 15 s 後に開く (ATA70_80 p.549–555 (80)、LH36 p.26 (36-00))。抽気側の詳細は ATA-36.md。
  - CF6 では start relay から APU 制御器に増風の要求（手動は START を引いた時点、auto は RUN の後）。50% N2 で終わる (ATA70_80 p.556–557)。
- Cutout: 50% N2 で START switch が戻り、start valve と bleed air valve が閉じ、Start light が消え、始動用の点火が止まる (FCOM p.879)。CF6 は N2 speed card の <50% 接点が hold-in solenoid の地絡を切る (ATA70_80 p.554・p.570)。
- STARTER CUTOUT n: start valve が閉じない (FCOM p.902)。CF6 は ECU が「valve open かつ N2 >54%」を判定し、EIU が 5 s 遅らせる。地上では発生時に他の caution・advisory を 20 s 抑止 (ATA70_80 p.558–559)。
- ENG n START VLV: CF6 は START switch と valve の不一致 8 s、または地上 autostart で valve が 20 s 以内に開かない (ATA70_80 p.558–559・p.564–565)。PW は START を引いても PRSOV が逆流に開かない (LH36 p.68 (36-10))。
- 手動始動:
  - GE: AUTOSTART OFF → START を引く（start・bleed valve 開、Start light）→ fuel-on indicator で RUN（spar・metering・engine fuel valve 開、選択 igniter）→ 50% で cutout → idle まで監視 (FCOM p.882 (7.20.12))。中止の条件は RUN 後 25 s で EGT 上昇なし、idle N2 で N1 回転なし、EGT が start limit に接近・超過、N2 が idle に安定しない、idle までに油圧が正常でない (FCOM p.184 (SP.7.2))。
  - 109: max motoring（N2 が fuel-on 以上で 5〜10 s 上昇なし）で RUN。中止の条件は 20 s で EGT 上昇なし、40% N2 で N1 回転なし、EGT が start limit、RUN 後 2 min で idle にならない、油圧 (FCOM p.185–186 (SP.7.3–4))。405 の通常始動もこの手順 (FCOM p.125 (NP.21.31))。
  - igniter は地上 1 本、空中 2 本 (FCOM p.882)。
- Autostart（109、570）:
  - AUTOSTART ON で arm。START を引くと start valve を arm し bleed valve を開く。RUN で開始。EEC が start valve を開き、所定の N2 で metering valve を開いて igniter に通電する (FCOM p.879)。CF6 は 15% N2 超 (ATA70_80 p.564–565)。
  - 監視は GE が EGT と N2、109 が N1・EGT・N2（idle 安定まで）(FCOM p.880 (7.20.10))。
  - 地上で中止する故障は hot start、hung start、no EGT rise。GE は油圧と N1 回転を、109 は油圧を監視しない (FCOM p.880)。
  - GE 地上 (FCOM p.880):
    - no EGT rise は燃料と点火を切って 30 s motoring、両 igniter で再試行。3 回で中止し、30 s motoring の後に start・bleed valve を閉じる。
    - cutout 前の hot / hung start の兆候は燃料を切り、fuel schedule を調整して再投入。3 回で中止（燃料・点火 off、30 s motoring、valve 閉）。
    - cutout 後の hot / hung は即中止、motoring なし。
    - ATA の数値: light-off の窓は 1 回目 20 s、2・3 回目 15 s。hot/hung の再試行は 6 s motoring と schedule −7%。3 回目の後は 2 min motoring（FCOM は 30 s。FCOM に従う）(ATA70_80 p.564–567)。
  - 109 地上: cutout 前の no EGT rise と hot start は燃料・点火を切り 30 s motoring、両 igniter で再試行、2 回で中止。hung start は motoring も再試行もしない。中止時は燃料・点火・始動空気を切り motoring しない。cutout 後の hot/hung は即中止 (FCOM p.881 (7.20.11))。
  - 空中: GE は hung start か EGT の takeoff limit で燃料を切って再投入し、start limit を超えて takeoff limit まで許す。自動中止せず idle 安定か CUTOFF まで続ける。109 は hot start で切って再投入し同様に続ける (FCOM p.881)。CF6 の windmill: dN2/dt <15 rpm/s が 15 s で stall。stall かつ EGT >750 °C は 6 s 切って減量、<750 °C は増量。EGT >960 °C は 6 s 切って減量 (ATA70_80 p.568–569)。
  - Auto-relight（GE）: N2 の急減か N2 < idle で flameout と判定し両 igniter。空中始動と relight は idle で安定させてからレバー位置へ (FCOM p.881)。109 は autostart ON のときだけ flameout で点火 (FCOM p.864・p.883)。
  - NP: GE は idle N2 までに N1 回転と油圧、109 は 40% N2 までに N1 回転を確認 (FCOM p.123–124 (NP.21.29–30))。
- Starter の制限（参考）: 1 min ON / 30 s OFF は無制限、5 min ON の後 2.5 min、2 回続けたら 10 min 冷却。N2 >30% での再エンゲージは損傷の恐れ (ATA70_80 p.536)。

### 4.7 点火

- GE (FCOM p.882–883 (7.20.12–13)):
  - エンジン単位で点火が選ばれるのは START switch out、NAI ON、flameout 検出。全エンジンで選ばれるのは TE flaps が UP 以外、CON ON。
  - 選ばれた igniter は FUEL CONTROL RUN（autostart 中は EEC の指令時）で通電し、CUTOFF で切れる。
  - 電源は AC が通常、STBY が backup。NORM で AC が無いと standby が両 igniter に連続給電。STBY 1/2 は AUTO 選択や EEC に関係なく当該 igniter に連続給電。
- 109: flameout での点火は autostart ON のときだけ。AC が無いときの standby は igniter 1 だけ (FCOM p.883)。
- CF6 の relay 論理 (ATA70_80 p.260–271 (74-31)):
  - SINGLE / DUAL ENABLE は ground 方式で ECU に入る。FUEL CONTROL の relay R8234 が CUTOFF（または fire switch）で全部を切る。
  - R7840/R7841 を励磁するのは START switch、CON（R8297）、flaps not retracted（R7532/R7533）、engine TAI（R7634）。AUTO = SINGLE なら SINGLE ENABLE、BOTH なら DUAL ENABLE。
  - STBY relay（R7467/R7471）は STBY 選択か bus 喪失で弛緩し、その系統の電源を STBY に切り替え、DUAL ENABLE を接地し、EIU に STBY IGN ON を送る。
  - 地上 SINGLE は始動ごとに前回と反対の系統（FCOM は「2 回ごと」。FCOM に従う）。空中始動は AUTO 位置に関係なく両方。
  - battery bus OFF でも ground handling bus が生きていれば、CUTOFF 時は R8619 で点火を禁止する (ATA70_80 p.262–263・p.270)。
- ENG IGNITION は CF6 では STBY が NORM のときだけ (ATA70_80 p.268–269)。
- 運用: CON は中〜強い雨、雹・霙、中〜強い乱気流、火山灰、着氷域に入るとき ON。使えなければ STBY (FCOM p.183 (SP.7.1))。NAI ON で自動的に連続点火になる (FCOM p.82 (L.10.6))。

### 4.8 逆推力

- 共通 (FCOM p.893–894 (7.20.23–24)):
  - fan air reverser で地上だけ。レバーの interlock で forward と reverse は同時に動かない。reverse lever down で stowed & locked。
  - reverse lever を idle detent まで上げると forward lever がロックされ、reverser が unlock して deploy。REV は amber（unlocked / moving）→ green（fully deployed）。interlock が外れ full reverse まで動く。
  - lever を全部下げると stow。移動中は REV amber、stowed & locked で消える。reverse lever が下がりきるまで forward lever は前に出ない。
  - 不意の deploy に対し、空気（GE）または油圧（PW）で stow して lock する。
- CF6 (ATA70_80 p.444–475 (78-34/78-30)):
  - reverse lever 6° で T/R PRSOV が開く（R7142/R7128 で flight idle、TAI valve 閉、HPSOV/PRV 強制開、LE flap 信号）。30° で DPV が開いて deploy 開始。47° の interlock stop が reverse idle、89.25° が full。
  - 両 cowl が >60%（RVDT）で ECU が interlock を外す。<20% かつ TRA が stow で再ロック。両 cowl が <15% になると forward 推力の増加を許す (ATA70_80 p.454–460)。
  - 両 deploy switch が DEPLOYED で PRSOV 閉、green REV。amber は「どちらかが unstowed で、両方は deployed でない」(ATA70_80 p.466・p.473–475)。
  - deploy 系は地上（R8015）だけ。stow 系は air/ground を通らないので auto-restow は空中でも働く (ATA70_80 p.452・p.474)。
  - ECU は reverser が stowed でないときだけ逆推力を制御し、TLA の関数で最大 max rated thrust の 90%（full reverse かつ両 cowl deployed）。stowed でないのに TLA が forward 域なら idle (ATA70_80 p.206・p.208)。
  - ENG n REVERSER は DPV の圧力スイッチと指令の不一致 2 s（地上は指令と圧、空中は圧あり）。REV n INTERLOCK（status）は interlock 未 retract で TRA >43° が 10 s。ENG n REV POS（status）は ECU が位置を検知できず reverse idle まで (ATA70_80 p.232・p.442・p.456–457・p.462・p.473–475)。
  - deploy・stow の所要時間は資料に記載なし。
- 手順: 接地後ただちに reverse lever を interlock まで上げ、外れたら必要なだけ逆推力。60 kt までに戻し始め、taxi 速度の前に reverse idle、その後 full down (FCOM p.148 (NP.21.54))。空中での逆推力と後退は禁止 (FCOM p.82)。

### 4.9 オイル

- CF6: 油圧は無調圧（容積式ポンプ）。低圧スイッチは上昇 15 psid で open、下降 10 psid で close → ENG n OIL PRESS。停止中に open なら status OIL PRESS SNS (ATA70_80 p.486・p.522–523 (79))。
- CF6: scavenge filter の ΔP スイッチは 33 psid で close → ENG n OIL FILT（bypass は約 40 psid から）(ATA70_80 p.510・p.522–523)。
- 表示: OIL P と OIL T は caution 域で amber、限界で赤。GE の OIL P は停止中と始動中は白のまま (FCOM p.846–848 (7.11.6–8))。OIL Q は low（GE は differential も）で magenta (FCOM p.849)。
- GE の巡航中: 1 基の量が他と所定量以上違うと OIL Q を出し、最も少ない値を magenta。量が増えた場合（指示故障や fuel/oil HX の漏れ）も出て、そのときは正常な低い方が magenta (FCOM p.890 (7.20.20))。
- 油圧は上流、油温は下流で計測 (FCOM p.890)。CF6 の油温は scavenge 出口（冷却前）(ATA70_80 p.518・p.524)。
- PW の値は資料に記載なし。

### 4.10 振動（AVM）

- 最も大きい source を表示し、source が決まらなければ BB（平均）(FCOM p.849–850・p.894)。
- CF6: 各信号を limit と比べ worst case の rotor を送る。速度信号の喪失か tracking filter の故障で BB。readout 0–5 units (ATA70_80 p.365–369 (77-31))。
- high band（白）は自動表示の level (FCOM p.849)。CF6 は 4.0 (ATA70_80 p.395)。

### 4.11 超過表示と色

- 白 = 正常域、amber = caution 域、赤 = 限界。正常域に戻ると白に戻るが、digital の枠は赤のまま残り、CANC で白、RCL で赤に戻る (FCOM p.872–873 (7.20.2–3))。
- CF6: 赤は bar と readout。max N2 の超過が 20 s を超えると N2 は赤のまま。枠の赤は EIU の exceedance 記録の印 (ATA70_80 p.334・p.345–346・p.355–356)。
- EGT amber の抑止は TO/GA switch を押してから 5 min（PW は 1 発故障・停止で 10 min）(FCOM p.872)。CF6 の ATA は「TO/GA mode で amber に入ってから 5 min」(ATA70_80 p.356)。FCOM に従う。
- EGT start limit は FCOM が「CUTOFF で表示し所定 N2 まで」、CF6 の ATA が「最初の RUN から min idle 安定まで」(FCOM p.838・p.879、ATA70_80 p.356–357)。FCOM に従う。

### 4.12 エンジン故障の検出

- ENG n FAIL は failure または flameout、地上は抑止 (FCOM p.899)。CF6 の条件は N2 <52%、oil pressure <70 psi、fuel control ON、GCB open、air mode (ATA70_80 p.230)。AND/OR の組み合わせは資料に明記なし。推定: N2 <52%、fuel ON、air は必須（GE の IDG underspeed は 55.3% N2 (LH24 p.66) なので GCB open はほぼ同時に成立）。
- IDG の underspeed（4,525 rpm）は PW 54.3% N2、GE 55.3% N2、RR 50.0% N3、air mode 信号（6,100 rpm）は PW 73.3%、GE 74.6%、RR 67.4% N3 (LH24 p.66 (24-10))。

### 4.13 RR（コードのみ、資料なし）

- EPR 制御。レバー → EPR 指令は 0.95 から（max EPR ×0.99）まで (EEC.RR:17-20)。
- N1・N2・N3・EPR は X-Plane の推力から回帰式で計算、EGT は X-Plane EGT ×785/960 (EEC.RR:394-660)。
- 逆推力中は N1 >91% なら acf の最大推力を毎フレーム 250 N 減らす（コメントは TCDS の 91%）(EEC.RR:504-513)。
- EGT 色の閾値は 600 / 733 / 785 °C (ENG:2197-2200)。パネルの N2 赤は >109.5%、N3 赤は >101.5% (ACF:126644・126965)。

## 6. 実装上の注意

- 現状の構造:
  - 推力・N1・N2・EGT・FF は X-Plane の `JET_2SPOOL` モデル。プラグインは `override_throttles` を立て、EEC の PID で `ENGN_thro_use` を動かして目標 N1（GE）/ EPR（PW・RR）に合わせる (EEC:751-819)。
  - 表示の N1・EPR は X-Plane の推力からの回帰式、N2 は表示 N1 の関数、EGT は X-Plane EGT の比例換算。表示値と X-Plane 内部の N1/N2 は別物 (EEC.PW:306-482、EEC.GE:314-439)。
  - 始動は X-Plane の starter コマンドの保持、点火は `igniter_on`、燃料は mixture と燃料系の `has_fuel_flow_before_mixture` (ENG:1745-1799・2047-2135、FUEL:2013-2016)。
  - idle は X-Plane の `high_idle_ratio`（全エンジン共通の 1 値）を書き換える (EEC.GE:47-77)。
- 再構築の方針案:
  1. 推力の物理は X-Plane のモデルを土台に残す。EEC は型式ごとの rating から max N1（GE）/ max EPR（PW）を計算し、TLA から指令値を作り、`ENGN_thro_use` を閉ループで合わせる。
  2. 表示は X-Plane の N1・N2（と PW は EPR）をそのまま使う方向にする。X-Plane の N1 が実機の N1 に合うよう acf（N1 at rated thrust、idle、推力の速度・高度特性）を調整する必要があり、acf の変更は承認が要る（ACF_DIFF §3.2）。PW の内部値は資料に無いので、FCOM PI の EPR 表と表示例に合わせる（推定）。
  3. `high_idle_ratio` は全エンジン共通なので、エンジン別の approach idle（LOW IDLE、IDLE DISAGREE を出すのに要る）は、X-Plane の idle を min idle に合わせたうえで、エンジンごとに `ENGN_thro_use` の下限（N2 目標）で作る。
  4. 始動はエンジンごとの状態機械（manual / autostart / 空中 / windmill）にし、出力で X-Plane の starter、igniter、燃料を動かす。light-off は `engine_is_burning_fuel` と EGT の上昇、hung は dN2/dt で判定する。
  5. 逆推力は X-Plane の reverser（`prop_mode` 3 と deploy ratio）を使い、interlock（>60% で解放）、90% 制限、PW の油圧と GE の抽気・エンジン運転の条件、auto-restow をプラグインで作る。
  6. メッセージの段階（ENG FAIL を caution、SHUTDOWN は master caution なし）は警報モジュールにメッセージごとの aural と master caution の属性が要る。ATA 31 担当と調整する。
- パネル定義（acf）に手を入れないとできないもの（承認が要る）: red box の保持、二次エンジン exceedance cue、partial / compact 形式、X-BLD と in-flight start envelope、VIB の source ラベル（今は BB の画像固定、ACF:129073）、GE の EGT の色と TO/GA 5 min 抑止（GE はパネルの閾値 925/960 で色が決まる、ACF:122260）、OIL P の amber band、OIL Q の magenta。dataref の値だけで直せるのは PW/RR の EGT 色（`EGT/amber_on` など）、各表示値、fuel-on と oil の赤の条件。
- INTERFACES.tsv の抜け: パネルの SHOW_* 条件だけで使う dataref が入っていない（全体で 175 個）。エンジン系は `EGT/amber_on`・`white_on`・`amber_inhibit`、`thrust_ref`、`EICAS2_oil_press_status`、`fuel_on_indicator_status`、`display_ref_line_magenta`。これらも名前と意味を保つ。
- 単純化してよいもの: VSV・VBV・クリアランス制御・bore cooling（表示は整備ページだけ、ATA70_80 p.314–315）、EEC の channel 切替と dispatch の status、CMC の整備ページ、starter の duty cycle（警告程度で可）、燃料 filter と heater の内部。
- 単純化してはいけないもの: レバーと推力の関係（full forward = max rated、上昇中にレバー固定で推力一定）、approach / min idle と 5 s、ALTN の挙動と A/T 切断、始動の順序と 50% cutout、点火の条件、逆推力の interlock と REV 表示、メッセージの段階と抑止、N1・N2・EGT の限界色。
- 型式の選択はリバリーごとの simconfig の `engines` 文字列。今は `string.match` で判定していて、"B1F" が "B1F1" に、"524H" が "524H8T" に先に一致する（ENG-30）。再構築では完全一致にする。

## 8. 作り直しか部分修正か

- 推奨: B747.40.engines（エンジン部分）と B747.42.EEC を作り直す。dataref とコマンドの名前・意味は §5 の一覧（INTERFACES.tsv と、そこに抜けている SHOW_* 用の dataref）を保つ。
- 理由:
  - 中心の推力則（レバー → 指令 → 上限）が概念から違い（ENG-01〜03・05）、直すと EEC の関数のほとんどを書き直すことになる。
  - B747.42 には EEC の推力制御、FMC の推力基準（ecc_mode_set と TO/CLB/CRZ/GA の計算、EEC:683-719、EEC.GE:120-310 など）、A/T の throttle servo（EEC:878-1006）が混在している。A/T・FMC 担当の作り直しとも境界を切り直す必要がある。
  - 表示値は 2021 年に純正 acf の推力モデルへ当てた回帰式で、acf を変えるとずれる（ENG-33・34）。
  - engines.lua は 4 基分のコピーが多く、添字の誤り（ENG-16・27）が出ている。始動・点火・autostart はエンジンごとの状態機械が要り、今の形を伸ばすより作り直す方が速く安全。
- 分け方の案: (a) EEC 本体（型式ごとの rating、TLA → 指令、idle、ALTN、overspeed、逆推力の制限）、(b) 始動・点火・燃料弁の sequencer、(c) 表示値と色・超過（N1/N2/EGT/EPR/オイル/振動）、(d) エンジンの EICAS メッセージ、(e) 逆推力。FMC の推力基準と A/T はそれぞれの担当のモジュールへ移す。
- 先にできる小さな修正（S、作り直しまでの暫定）: ENG-08・09（段階と条件）、ENG-10・11、ENG-13、ENG-16、ENG-19、ENG-30、ENG-32。
